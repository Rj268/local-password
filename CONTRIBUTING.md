# Contributing

Report bugs and propose changes through [GitHub Issues](https://github.com/Rj268/local-password/issues). Include the app version, operating system, steps to reproduce, and expected and actual behavior. Use test accounts and synthetic vaults in screenshots and attachments. Follow [SECURITY.md](SECURITY.md) for sensitive reports.

Discuss substantial changes in an issue first. Keep pull requests focused, explain user-visible behavior, and record checks performed and platform limitations.

Follow the [build and test guide](docs/BUILDING.md). Add regression coverage for changes to vault writes, duplicate handling, encryption, imports, and browser origin matching. Preserve vault compatibility and equivalent desktop/Android behavior; document platform differences.

Do not commit personal vaults, credentials, signing material, generated installers, or personal test data. Preserve third-party licenses and attribution. Release packages belong in the appropriate distribution channel.
