Local Password

Double-click "Install Local Password" in the folder above this one.
The app then appears in the Start menu and on the desktop.

You can also open LocalPassword.exe in this folder. Leave the other files beside it.

Generate makes a password. Copy puts it on the clipboard. Save is optional.
The first save asks for a passphrase and then shows a recovery key once.
Write that key down. Either one opens the saved passwords.

Settings holds Light / Dark / System theme, clipboard clear, and auto-lock.
Saved passwords live in:
  %LOCALAPPDATA%\local-password\saved.vault
Uninstall from Settings > Apps, or run uninstall.ps1 in the install folder.
Uninstall removes the app; it does not delete your vault file.

Privacy: no account, no analytics. Optional breach checks send only a short
hash prefix to Have I Been Pwned — never the password or vault.
See PRIVACY.md and SECURITY.md in the project (or beside this build when included).

Windows may say it protected your PC. Choose More info, then Run anyway.
That warning is normal until the .exe is signed with a code-signing certificate.
