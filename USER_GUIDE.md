# Local Password — quick guide

## First time

1. Open Local Password.
2. Skim or skip the short welcome.
3. Open **Generate**, make a password, give it a name, then **Save**.
4. Choose a passphrase (at least 8 characters). Write down the recovery key shown once.

## Every day

- **Generate** — Characters or Words. Use **Also exclude** when a site rejects certain symbols.
- **Saved** — Search, copy, or replace a password. Extra actions (favorite, archive, edit, breach check on one row) are under **More**.
- **Lock** — Hides the vault until you unlock with the passphrase or recovery key.
- **Settings → Lock on open** — Optional. When on, the app asks for the passphrase as soon as it starts.
- **Saved → Check breaches** — Optional. Asks a public leak list whether a password appeared in known breaches. Only a short hash prefix is sent — not the password or vault.

## Backup

- **Settings → Export vault** copies the encrypted file. Keep it private.
- **Import vault** replaces the vault on this computer after a warning.
- Send / Receive vault moves that encrypted file to another device on the same Wi-Fi. The passphrase is not sent.

## Privacy

Nothing is uploaded for analytics or advertising. Passwords stay on this computer. See `SECURITY.md` before a public release.
